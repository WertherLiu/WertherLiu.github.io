# 时间序列分析

## 第一章 时间序列分析简介

### 1.1 时间序列的定义
时间序列即依照时间顺序把随机事件变化过程记录下来，例如 \(X_1, X_2, \dots\)。

### 1.2 对时间序列数据分析方法
- **频域分析方法（谱分析）**
- **时域分析方法**
  - 基本思想：事物的发展具有一定的惯性，因而可以从序列自相关程度揭示内在规律。
  - 模型发展：
    - 1927：AR（自回归）模型
    - 1931：MA（移动平均）模型
    - 1970：ARMA模型
    - 1982：ARCH（自回归条件异方差）
    - 1987：GARCH模型等

## 第二章 时间序列的预处理

### 2.1 平稳时间序列
- **特征统计量**
  - 低阶矩如均值、方差、自协方差、自相关系数等，用来描述时间序列。
- **平稳时间序列的定义**
  - **严平稳**：随时间推移，序列所有统计性质都不变。
  - **宽平稳**：序列的统计性质主要由低阶矩决定，只要低阶矩平稳，即可保证序列主要性质稳定。
    - 定义：对于时间序列，若
      1. \(\forall t \in T, E[X_t] = \mu\)（\(\mu\) 为常数）
      2. \(\forall t, s \in T\) 且 \(k = s - t\)，有 \(\gamma(t, s) = \gamma(k)\)，则序列为宽平稳时间序列。
    - 注：一般而言，严平稳蕴含宽平稳，但宽平稳中不一定是严平稳。
- **平稳时间序列性质**
  - 均值常数 \(E[X_t] = \mu\)
  - 自协方差函数和自相关系数只依赖于时间的平移长度而与起止点无关
  - 自协方差函数：\(\gamma(k) = \gamma(t, t + k)\)
  - 自相关函数：\(\rho(k) = \frac{\gamma(k)}{\gamma(0)}\)
  - 一个平稳时间序列有唯一的自相关函数，但一个自相关函数可对应多个时间序列。

### 2.2 平稳性检验
- 图检验：平稳的时序图应围绕一个中心上下波动，有趋势性一般不为平稳序列。
- 平稳序列通常具有短期相关性，随着延迟期数 \(k\) 的增加，平稳序列的自相关系数会很快趋向于零，反之非平稳序列的自相关系数趋向于零的速度较慢。

### 2.3 随机性检验
- **纯随机序列定义**：纯随机序列即白噪声序列，记为 \(WN\)。
  - 若 \(E[X_t] = 0\)，\(\text{Var}(X_t) = \sigma^2\)，且 \(E[X_t X_s] = 0\)（\(t \neq s\)），则 \(WN\) 是最简单的平稳序列。
- **纯随机性检验**
  - 引理（Bartlett）：对于 \(n\) 期的序列，自相关系数 \(\rho_k\) 在大样本下近似服从 \(N(0, \frac{1}{n})\)。
  - 假设检验：
    - \(H_0: \rho_1 = \rho_2 = \dots = \rho_m = 0\)（\(m > 1, k \leq m\)）
    - \(H_1\)：至少有一个 \(\rho_k \neq 0\)（\(k \geq 1, k \leq m\)）
    - 检验统计量：\(\chi^2 = n \sum_{k=1}^{m} \hat{\rho}_k^2\)
    - 改进：在大样本下效果好，但小样本下不够精确。

## 第三章 平稳时间序列分析

### 3.1 ARMA模型
ARMA是目前最常用的平稳序列拟合模型。

### 3.2 AR模型
- **定义**：
  \[
  X_t = \phi_1 X_{t-1} + \phi_2 X_{t-2} + \dots + \phi_p X_{t-p} + \epsilon_t
  \]
  其中 \(E[\epsilon_t] = 0\)，\(\text{Var}(\epsilon_t) = \sigma^2\)，且 \(\epsilon_t\) 与 \(X_{t-i}\)（\(i = 1, 2, \dots, p\)）无关。
  - 模型最高阶数为 \(p\)。
  - 当 \(\epsilon_t = 0\) 时，即为中心化 AR(p) 模型。
- **平稳性判断**
  - 特征根判别：任一 AR(p) 可视为一个非齐次线性差分方程，其特征根都在单位圆内。
  - 平稳域判别：AR(p) 稳定，\(\phi_p \neq 0\)。
- **AR(p) 的统计性质**
  - 均值：\(E[X_t] = \mu = \frac{\mu}{1 - \phi_1 - \phi_2 - \dots - \phi_p}\)。
  - 方差：需要借助 Green 函数。
  - 自协方差函数和自相关函数有递推公式。

### 3.3 MA模型
- **定义**：
  \[
  X_t = \mu + \epsilon_t - \theta_1 \epsilon_{t-1} - \theta_2 \epsilon_{t-2} - \dots - \theta_q \epsilon_{t-q}
  \]
  其中 \(E[\epsilon_t] = 0\)，\(\text{Var}(\epsilon_t) = \sigma^2\)。
- **MA(q) 的统计性质**
  - 均值：\(E[X_t] = \mu\)。
  - 方差：\(\text{Var}(X_t) = (1 + \theta_1^2 + \theta_2^2 + \dots + \theta_q^2)\sigma^2\)。
  - 自协方差函数和自相关函数在滞后 \(q\) 期后截尾。

### 3.4 ARMA模型
- **定义**：
  \[
  X_t = \phi_1 X_{t-1} + \phi_2 X_{t-2} + \dots + \phi_p X_{t-p} + \epsilon_t - \theta_1 \epsilon_{t-1} - \theta_2 \epsilon_{t-2} - \dots - \theta_q \epsilon_{t-q}
  \]
- **平稳条件与可逆条件**
  - 平稳条件：特征方程 \(\Phi(B) = 0\) 的根都在单位圆外。
  - 可逆条件：特征方程 \(\Theta(B) = 0\) 的根都在单位圆外。
- **统计性质**
  - 均值、自协方差函数、自相关函数等。

### 3.5 平稳序列建模
如果时间序列为平稳非白噪声序列，则可以利用 ARMA 建模。
